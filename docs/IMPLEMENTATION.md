# План реализации WEARO

Исходный репозиторий vrempel90-dev/wearo-miniapp пустой (9 октября 2026).
Архитектура: Next.js App Router, модульный монолит, PostgreSQL и Prisma.

1. Основа приложения и план.
2. Схема, миграция, проверка Telegram initData, сессии и серверные роли.
3. Каталог, изолированные кабинеты продавцов, загрузки в S3.
4. Корзина, сериализуемое оформление, резервы, статусы и комиссии.
5. Администрирование, журнал, возвраты, отдельный тестовый платёжный провайдер.
6. Unit/integration/HTTP проверки, production build, Docker, Railway и документация.

Production: без development login и без реального приёма денег. Постоянные данные —
PostgreSQL и объектное хранилище. Демонстрационные товары только через явный seed.
Нужны отдельно настроенные bot token, PostgreSQL, S3 и решение о размещении
персональных данных в Казахстане; наличие Railway не подтверждает соответствие.
