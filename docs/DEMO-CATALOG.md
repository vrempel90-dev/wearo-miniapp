# WEARO demonstration dataset

Все товары, магазины, заявленные материалы, цены, скидки и остатки вымышлены.
Точная маркировка интерфейса: «Демонстрационный каталог — заказы и оплата тестовые».
Популярная обувь — редакционная демонстрационная подборка, без статистики продаж.

Команды: `npm run db:migrate`, `npm run db:seed:demo`, `npm run demo:verify`.
Требуются NODE_ENV вне production, DEMO_SEED=true и TEST_PAYMENTS=true.
Повторный запуск не удаляет записи и не сбрасывает остатки/резервы. Seed использует
advisory lock PostgreSQL и одну транзакцию; неизвестные записи набора или коллизии
идентификаторов отклоняются, а не перезаписываются.

Набор содержит 15 продавцов, 500 товаров, 5400 вариантов и 125 скидок.
Распределение: 150 женской одежды, 100 женской обуви, 150 мужской одежды, 100 мужской обуви.
Одежда: XS–XL для женских моделей, S–XXL для мужских; обувь EU 36–41 / 40–45.
Каждый товар имеет два цвета и независимые остатки по размеру/цвету. Основное фото
показывает только основной цвет; альтернативный цвет отдельно не сфотографирован.
Цена после скидки находится в заданном диапазоне; старая цена и процент согласованы
целочисленной арифметикой и защищены CHECK в PostgreSQL.

Логотипы — созданные для проекта монограммы SVG. Фотографии генерируются индивидуально
встроенным image_gen, без чужих логотипов и водяных знаков. `public/demo/assets.json`
содержит происхождение и промпт каждого подготовленного файла. `scripts/demo-assets.ts`
экспортирует оригиналы в JPEG для сайта, не синтезируя изображения программно.
Seed связывает только существующие файлы с товарами; отсутствующие фотографии не
подменяются одним общим снимком. Покрытие изображениями проверяет `demo:verify`:
декодирование, размеры, уникальные SHA-256 и наличие файлов по каждому URL.

Тестовые заказы используют TEST_SUCCEEDED и TEST_REFUNDED, не PAID. Реальные платежи
отключены. Демо-товары не оформляются в production, где тестовый платёжный режим
запрещён. Для реального открытия в Telegram нужны бот, HTTPS-развёртывание и отдельная
проверка; локальная симуляция не подтверждает живую Telegram-сессию.
